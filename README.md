# Image Pro - โปรแกรมขยายขนาดและเพิ่มความคมชัดรูปภาพ

แอปพลิเคชันเดสก์ท็อประดับมืออาชีพ พัฒนาด้วย **Python 3**, **PyQt6**, **PyTorch**, และ **OpenCV**
สำหรับขยายขนาดภาพ (Image Upscaling) และเพิ่มความคมชัด (Image Sharpening) โดยเฉพาะ

---

## 🌟 จุดเด่นและความสามารถหลัก

### 1. การขยายขนาดรูปภาพ (Image Upscaling)
- **AI Super-Resolution (Real-ESRGAN)**:
  - `RealESRGAN_x4plus`: โมเดลอเนกประสงค์สำหรับภาพถ่ายทั่วไป คมชัดสูงสุด ขยาย 4 เท่า
  - `RealESRGAN_x4plus_anime_6B`: โมเดลสำหรับภาพการ์ตูน ภาพวาด อนิเมะ ขยาย 4 เท่า ประมวลผลรวดเร็ว
  - `RealESRGAN_x2plus`: โมเดลขยาย 2 เท่าสำหรับภาพถ่าย ให้รายละเอียดเส้นขอบคมชัดเป็นธรรมชาติ
  - **Tiled Inference Engine**: ระบบแบ่งภาพเป็นบล็อกย่อยอัตโนมัติ ช่วยให้ประมวลผลภาพขนาดใหญ่ได้โดยที่ RAM/VRAM ไม่เต็ม
  - **Native PyTorch Architecture**: ไม่ต้องพึ่งพาแพ็กเกจภายนอกที่อาจติดตั้งยาก รองรับทั้ง CPU และ GPU (CUDA)
- **Traditional Interpolation (OpenCV)**:
  - `Lanczos`: คมชัดสูงสุดสำหรับอัลกอริทึมดั้งเดิม (แนะนำ)
  - `Bicubic`: ความคมชัดระดับมาตรฐาน นุ่มนวล
  - `Bilinear`: ขยายเร็ว เหมาะกับภาพทั่วไป
  - `Nearest Neighbor`: เร็วที่สุด เหมาะกับภาพ Pixel Art
- **กำหนดขนาดได้อย่างอิสระ**:
  - เลือกอัตราส่วนคงที่: 1.5x, 2x, 3x, 4x, 6x, 8x
  - หรือระบุขนาดพิกเซล กว้าง × สูง (Width × Height) ได้โดยตรง

### 2. การเพิ่มความคมชัด (Image Sharpening)
- **Unsharp Mask**: ปรับแต่งค่ารัศมี (Radius), ความแรง (Amount), และขีดจำกัด (Threshold) ได้อย่างละเอียด
- **Laplacian Filter**: ตัวกรองอนุพันธ์อันดับสองเพื่อเน้นเส้นขอบภาพอย่างแม่นยำ
- **Detail Enhancement**: ตัวกรองรักษารูปขอบ (Edge-preserving filter) เพื่อดึงรายละเอียดในเงามืดและแสงสว่าง
- **โหมด Luminance Only**: ปรับความคมชัดเฉพาะช่องความสว่างในระบบสี LAB ป้องกันการเกิดสัญญาณรบกวนของสี (Color Fringing / Chrominance Noise)
- **Intensity Slider**: ปรับความเข้มของการผสมผลลัพธ์ (Blend) ตั้งแต่ 0% ถึง 100%

### 3. ส่วนติดต่อผู้ใช้และเครื่องมือแสดงผล (UI/UX)
- **โหมดเปรียบเทียบ 3 รูปแบบ**:
  - `สไลเดอร์เปรียบเทียบ (Split Slider ◀▶)`: ลากเส้นแบ่งภาพเพื่อดูความแตกต่างระหว่างก่อนและหลัง ณ ตำแหน่งเดียวกัน
  - `แสดงคู่กัน (Side-by-Side)`: แสดงภาพก่อนและหลังคู่กันซ้าย-ขวา เลื่อนและซูมพร้อมกันอย่างสมบูรณ์แบบ
  - `ภาพเดี่ยว (Single Image)`: แสดงเฉพาะภาพผลลัพธ์เพื่อการตรวจสอบเต็มหน้าจอ
- **ระบบซูมและนำทาง**:
  - ซูมเข้า/ออกด้วยล้อเลื่อนเมาส์ โดยอิงจุดกึ่งกลางที่ตำแหน่งเคอร์เซอร์ (Mouse-anchored Zoom)
  - เลื่อนดูภาพ (Pan) ด้วยการคลิกลาก หรือกด `Spacebar` ค้างไว้
  - ดับเบิลคลิกเพื่อปรับขนาดพอดีหน้าต่าง (Fit to Screen)
- **Pixel Inspector HUD**:
  - แสดงพิกัด (X, Y) และค่าสี RGB ของพิกเซลใต้เคอร์เซอร์เมาส์แบบเรียลไทม์ พร้อมตัวอย่างสี
- **ประมวลผลแบบแบตช์ (Batch Processing)**:
  - ลากไฟล์หลายรูปเข้ามาพร้อมกัน หรือเลือกทั้งโฟลเดอร์
  - ประมวลผลในเบื้องหลัง (Background Thread) โดย UI ไม่ค้าง พร้อมบันทึกลงในโฟลเดอร์ `image_pro_output` อัตโนมัติ
- **พรีเซ็ตสำเร็จรูป (Quick Presets)**:
  - 📸 ขยายภาพถ่าย (AI 4x + คมชัดสมดุล)
  - 🎨 ขยายภาพการ์ตูน/อนิเมะ (AI Anime 4x)
  - ⚡ ขยายด่วน (Lanczos 2x + Unsharp Mask)
  - ✨ เพิ่มความคมชัดเท่านั้น (ไม่ขยายภาพ)

## 🚀 วิธีการติดตั้งและการใช้งาน

### 1. ติดตั้งไลบรารี

```bash
pip install -r requirements.txt
```

### 2. เริ่มต้นใช้งาน

**วิธีที่ 1:** ดับเบิลคลิกที่ไฟล์ `run.bat` บน Windows

**วิธีที่ 2:** รันผ่านคำสั่ง Terminal:
```bash
python main.py
```

## ⌨ คีย์ลัด (Keyboard Shortcuts)

| คีย์ลัด | การทำงาน |
|---|---|
| `Ctrl + O` | เปิดไฟล์รูปภาพ |
| `Ctrl + Shift + O` | เปิดโฟลเดอร์สำหรับประมวลผลแบตช์ |

| `Spacebar + ลากเมาส์` | เลื่อนดูส่วนต่างๆ ของภาพ (Pan) |
| `ดับเบิลคลิกบนภาพ` | ซูมพอดีหน้าต่าง |

## 📄 รูปแบบไฟล์ที่รองรับ

- **PNG** (`.png`) — รักษาความโปร่งใส (Alpha Transparency) อย่างสมบูรณ์
- **JPEG** (`.jpg`, `.jpeg`) — กำหนดระดับคุณภาพได้ 1-100%
- **WebP** (`.webp`) — บีบอัดคุณภาพสูง
- **BMP** (`.bmp`)
- **TIFF** (`.tiff`, `.tif`)
